    Browser CDP

    Opens the separate Chrome that Web: steps drive — sign in there once, and use F12 to look up selectors. "Record clicks" watches that browser from inside the page: click through what you want automated and the steps appear above, with a hover step added automatically when you use a dropdown menu. Stop, then Save as usual. Your own Chrome is never touched.

    Replay Current Recording

    Runs in the background in this priority order: UIA invoke → posted window messages → physical mouse/keyboard (only if you explicitly allow it below). This replays whatever's currently in the step list above -- handy for testing before you decide whether to save it.
