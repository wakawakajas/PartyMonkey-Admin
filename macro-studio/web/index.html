      New to this? Read once — it is all three ideas

      1. Steps run top to bottom. Add them with the picker above, drag with the grip, and press Save changes when you are done. Nothing runs until you press play back in the viewer. A step that fails does not stop the run unless you tick stop run if this fails on it.

      2. Steps hand values to each other by name. A step with a store as box saves what it found under that name; every later step can use it in double braces. Name it rows in a Read-spreadsheet step, and a Loop set to each walks that list with the current one available as {{row}}. {{date}}, {{time}} and {{now}} are always there, with a format if you want one: {{date:DD-MM-YYYY}}, {{time:hAP}} for 9AM. Folders take %USERPROFILE% so a macro still works on someone else's machine.

      3. Loops and If steps hold their own steps. They grow a Loop body (or Then/Else) box with its own + Add Step button — the steps that repeat go in there, not at the bottom of the page.

      To find the CSS selector a web step asks for: open the CDP browser, press F12, click the arrow icon at the top left of the panel that opens, click the thing on the page, then right-click the highlighted line and choose Copy › Copy selector. Or skip it and use the visible words on the button instead — that field is optional.
