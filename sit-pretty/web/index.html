Save a packing clip for an order

Downloads the minutes an order was packed straight from the packing cameras' memory cards (nothing is recorded on this PC in between). Put BigSeller's "Scan to ship" time and choose how many minutes before and after it the clip covers (5 before by default). A 15-minute window takes about 4 minutes to download. The cameras only keep video when something moves, so quiet minutes are skipped.

Only have the order ID? Leave the times empty and press Download: Claude looks up the Scan to ship time in BigSeller, then the clip downloads by itself (about 5-10 minutes; see Evidence video).
