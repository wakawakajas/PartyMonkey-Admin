Ask Claude to make a packing evidence video

Pick the return and tick the camera(s) that filmed the packing. Claude downloads that footage from the camera's memory card, labels every item, the counting, taping and waybill, and saves Shopee-ready videos (VIDEO 1/2 ...) into the order's folder. It checks for new requests every hour from 9am to 9pm.

Save a packing clip for an order

Downloads the minutes an order was packed straight from the packing cameras' memory cards (nothing is recorded on this PC in between). Put BigSeller's "Scan to ship" time: the clip runs from 15 minutes before to 1 minute after, and you can change both. A 15-minute window takes about 4 minutes to download. The cameras only keep video when something moves, so quiet minutes are skipped.

Only have the order ID? Leave the times empty and press Download: Claude looks up the Scan to ship time in BigSeller, then the clip downloads by itself (about 5-10 minutes; see Evidence video).
